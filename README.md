# Система бронирования переговорных комнат 🏢

Frontend-приложение для поиска, бронирования и управления переговорными комнатами в различных офисах. Разработано в рамках тестового задания для стажеров Frontend (осенняя волна 2026).

## 🚀 Запуск проекта

Убедитесь, что у вас установлен Node.js версии 20 или выше.

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   
```bash
git clone https://github.com/talense-tasks/frontend-trainee-assignment-autumn-2026-flow-2-areallypawa-bf00542a
cd book-room
```

2. **Установите зависимости:**
   
```bash
npm install
```

3. **Запустите проект в режиме разработки:**
   
```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173` (или другому порту, указанному Vite).

## 🧪 Запуск тестов

В проекте настроено юнит-тестирование с использованием **Vitest** и **React Testing Library**. Тестами покрыты утилиты работы со временем и изолированные UI-компоненты.

* Запуск тестов в консоли:
```bash
npm run test
```

* Запуск тестов с визуальным UI в браузере:
```bash
npm run test:ui
```

## 🛠 Архитектура и стек технологий

Проект построен с упором на производительность, строгую типизацию и переиспользуемость UI-компонентов.

* **Ядро:** React 18, TypeScript, Vite.
* **Роутинг:** `react-router-dom` (с обработкой 404 ошибок и редиректами).
* **Стилизация:** CSS Modules. Выбраны для обеспечения строгой изоляции стилей без оверхеда на runtime (в отличие от CSS-in-JS).
* **Управление состоянием и API:** TanStack Query (React Query) + Axios.

## 💡 Принятые технические решения

Согласно требованиям задания, были приняты следующие архитектурные решения:

1. **Собственная дизайн-система без тяжелых библиотек**
Вместо использования готовых библиотек (MUI, Ant Design), все ключевые компоненты (`DateRangePicker`, `Dropdown`, `BookingModal`) были написаны с нуля. Это позволило точно попасть в предоставленные макеты Figma и продемонстрировать навыки работы с DOM.
2. **Real-time обновления через WebSockets и React Query**
Для синхронизации расписания в реальном времени реализован кастомный хук `useWebSockets`. При получении событий от сервера (`booking.created`, `booking.cancelled`, `room.availability_changed`), хук не управляет состоянием вручную, а инвалидирует соответствующие ключи кэша в `React Query` (`queryClient.invalidateQueries`). Это позволяет автоматически и бесшовно подтягивать актуальные данные с REST API, избегая рассинхронизации клиентского стейта и базы данных.
3. **Обработка временных зон (Timezones)**
Фильтрация бронирований и создание новых записей производится с учетом часового пояса и конца дня (`23:59:59`). В утилитах реализованы проверки на рабочие часы (с 09:00 до 20:00) и пересечения интервалов.
4. **Глобальный перехват оффлайн-режима**
На уровне рутового компонента `App.tsx` реализован слушатель событий `online`/`offline` с выводом предупреждающего баннера при потере соединения.
